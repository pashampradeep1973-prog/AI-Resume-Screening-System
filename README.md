# AI Resume Screening System

The AI Resume Screening System is a web-based application that helps recruiters automatically analyze and rank candidate resumes based on a given job description.

The system uses Natural Language Processing (NLP) techniques to extract skills from resumes and compare them with job requirements to generate a ranking score. This helps recruiters quickly identify the most suitable candidates.

---

## Features

### Resume Upload
Users can upload multiple resumes in PDF format for analysis.

### Job Description Input
Recruiters can enter the job description to define required skills and qualifications.

### Resume Analysis
The system extracts important information such as skills, keywords, and experience from uploaded resumes.

### Candidate Ranking
Candidates are ranked based on how well their resumes match the job description.

### Dashboard Visualization
A dashboard with charts displays resume scores for better visualization and comparison.

### Admin Login
Secure login page for administrators to access the system.

## How It Works

1. Login to the system
2. Enter the job description
3. Upload multiple resumes
4. Click "Analyze Resumes"
5. The system extracts resume information
6. Candidates are ranked based on matching score
7. Results are displayed in the dashboard
