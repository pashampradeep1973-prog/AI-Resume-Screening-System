# AI Resume Screening System

## Description
This project is an AI-based Resume Screening System that helps recruiters automatically analyze and rank resumes.

## Features
- Upload resumes
- Extract text from resumes
- Compare with job description
- Rank candidates

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript

## How to Run

Backend:
python manage.py runserver

Frontend:
Open index.html
